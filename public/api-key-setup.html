Get a free Groq or Gemini key

Habit Assistant's shared trial is limited, but Groq and Google Gemini both offer generous free tiers — pick either one below. It takes about a minute to set up, and after that your chats no longer share a limit with anyone else.

Option 1: Groq

  1. Go to console.groq.com and sign up — it's free, no card required.
  2. In the left sidebar, click API Keys, then Create API Key.
  3. Give it any name you like, click Submit, then copy the key it shows you — it starts with gsk_. Groq only shows it once, so copy it now.
  4. Back in Habit Assistant, open Settings (the ⚙ button), choose Groq as the provider, paste the key in, and click Save & use.

Option 2: Gemini

  1. Go to aistudio.google.com and sign in with your Google account — it's free, no card required.
  2. Click Create API key, then pick (or create) a Google Cloud project when prompted.
  3. Copy the key it shows you — Google is mid-transition on key formats, so it may start with AIza or AQ. depending on your account.
  4. Back in Habit Assistant, open Settings (the ⚙ button), choose Google Gemini as the provider, paste the key in, and click Save & use.

Two tips while you're creating the key: make a separate key just for Habit Assistant, so you can delete it on its own; and if the account has billing turned on (always the case for an Anthropic key), set a monthly spending limit.

Whichever you pick, the key is saved in your browser. Unless you tick Keep this key on this device only in Settings, it is also saved in your Habit Assistant data file in your own Google Drive, in plain text, so every device you sign in on can use it. A new Anthropic key starts with the box ticked. When you chat, the key passes through Habit Assistant's server on its way to the provider, and is never stored there. What plain text in Drive means.
